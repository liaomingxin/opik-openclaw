## Projects 页面所需全部 API 接口 + 数据结构汇总

以下是构建 Projects 页面（含项目列表 → 日志详情 → Traces/Spans/Threads 列表 → 详情面板）所需的 **全部 35 个后端接口**。

---

### 一、总览：组件 → API 调用关系图

```
ProjectsPage（项目列表）
├── GET  /projects/                        ← 项目列表
├── GET  /projects/stats                   ← 项目统计
├── POST /projects/                        ← 创建项目
├── PATCH /projects/{id}                   ← 编辑项目
├── DELETE /projects/{id}                  ← 删除项目
├── POST /projects/delete                  ← 批量删除
│
ProjectPage（项目详情壳）
├── GET  /projects/{id}                    ← 获取项目信息
│
LogsPage → TracesSpansTab（Traces/Spans 列表）
├── GET  /traces/                          ← Trace 列表
├── GET  /spans/                           ← Span 列表
├── GET  /traces/stats                     ← Trace 统计
├── GET  /spans/stats                      ← Span 统计
├── GET  /traces/feedback-scores/names     ← Trace 评分列名
├── GET  /spans/feedback-scores/names      ← Span 评分列名
├── POST /traces/delete                    ← 批量删除 Trace
├── PATCH /traces/batch                    ← 批量更新 Trace（加标签）
├── PATCH /spans/batch                     ← 批量更新 Span（加标签）
│
LogsPage → ThreadsTab（Threads 列表）
├── GET  /traces/threads                   ← Thread 列表
├── GET  /traces/threads/stats             ← Thread 统计
├── GET  /traces/threads/feedback-scores/names
├── POST /traces/threads/delete            ← 批量删除 Thread
├── PATCH /traces/threads/batch            ← 批量更新 Thread
│
TraceDetailsPanel（Trace 侧滑详情）
├── GET  /traces/{id}                      ← Trace 详情
├── GET  /spans/?trace_id=X               ← Trace 下所有 Span（树）
├── DELETE /traces/{id}                    ← 删除 Trace
├── PATCH /traces/{id}                     ← 更新标签
├── PUT  /traces/{id}/feedback-scores      ← 打分

├── POST /spans/comments/delete

│
ThreadDetailsPanel（Thread 侧滑详情）
├── POST /traces/threads/retrieve          ← Thread 详情
├── GET  /traces/?filters=[thread_id=X]    ← Thread 下的 Traces
├── PATCH /traces/threads/{id}             ← 更新标签
├── PUT  /traces/threads/feedback-scores   ← Thread 打分
├── POST /traces/threads/feedback-scores/delete
├── POST /traces/threads/{id}/comments
├── PATCH /traces/threads/comments/{id}
```

### 二、完整接口列表 + 数据结构

#### 📁 A. 项目管理（6 个接口）

##### A1. 项目列表

```
GET /v1/private/projects/
```

| 参数 | 类型   | 说明            |
| ------ | -------- | ----------------- |
| `page`     | int    | 页码，从 1 开始 |
| `size`     | int    | 每页条数        |
| `name`     | string | 按名称搜索      |
| `sorting`     | string | JSON: `[{"field":"last_updated_at","direction":"DESC"}]`          |

**响应：**

```typescript
interface ProjectPage {
  page: number;
  size: number;
  total: number;
  sortable_by: string[];      // ["id","name","last_updated_at","created_at","last_updated_trace_at"]
  content: Project[];
}

interface Project {
  id: string;                 // UUID
  name: string;
  description: string | null;
  visibility: "private" | "public";
  created_at: string;         // ISO-8601
  created_by: string;
  last_updated_at: string;
  last_updated_by: string;
  last_updated_trace_at: string | null;
}
```

##### A2. 项目统计

```
GET /v1/private/projects/stats
```

参数同 A1。

**响应：**

```typescript
interface ProjectStatsSummary {
  content: ProjectStatsSummaryItem[];
}

interface ProjectStatsSummaryItem {
  project_id: string;
  trace_count: number | null;
  thread_count: number | null;
  duration: { p50: number; p90: number; p99: number } | null;
  total_estimated_cost: number | null;
  total_estimated_cost_sum: number | null;
  usage: Record<string, number> | null;  // {"completion_tokens": 1234, ...}
  feedback_scores: FeedbackScoreAverage[] | null;
  guardrails_failed_count: number | null;
  error_count: { count: number; deviation: number; deviation_percentage: number | null } | null;
}

interface FeedbackScoreAverage {
  name: string;
  value: number;
}
```

##### A3–A6. 项目 CRUD

| 接口     | 方法 | 请求体     | 响应          |
| ---------- | ------ | ------------ | --------------- |
| 创建     | `POST /projects/`     | `{ name: string, description?: string }`           | `201` + `Location` 头含新 ID |
| 更新     | `PATCH /projects/{id}`     | `{ name?: string, description?: string }`           | `204`              |
| 删除     | `DELETE /projects/{id}`     | —         | `204`              |
| 批量删除 | `POST /projects/delete`     | `{ ids: string[] }` (1–1000) | `204`              |

#### 📊 B. Traces（13 个接口）

##### B1. Trace 列表

```
GET /v1/private/traces/
```

| 参数 | 类型     | 说明                  |
| ------ | ---------- | ----------------------- |
| `project_id`     | UUID     | **必须**                      |
| `page`     | int      | 默认 1                |
| `size`     | int      | 默认 10               |
| `filters`     | string   | JSON 编码的过滤器数组 |
| `sorting`     | string   | 排序 JSON             |
| `search`     | string   | 全文搜索              |
| `truncate`     | boolean  | 是否截断 input/output |
| `from_time`     | ISO-8601 | 时间范围起            |
| `to_time`     | ISO-8601 | 时间范围止            |
| `exclude`     | string   | 排除字段（逗号分隔）  |

**响应：**

```typescript
interface TracePage {
  page: number;
  size: number;
  total: number;
  sortable_by: string[];
  content: Trace[];
}

interface Trace {
  id: string;
  project_id: string;
  name: string;
  start_time: string;
  end_time: string | null;
  input: any;                              // 任意 JSON
  output: any;
  metadata: any;
  tags: string[];
  error_info: ErrorInfo | null;
  usage: Record<string, number>;           // {"completion_tokens": 50, ...}
  created_at: string;
  last_updated_at: string;
  created_by: string;
  last_updated_by: string;
  feedback_scores: FeedbackScore[];
  span_feedback_scores: FeedbackScore[];   // 从 span 聚合的分数
  comments: Comment[];
  guardrails_validations: GuardrailsValidation[];
  total_estimated_cost: number | null;
  span_count: number;
  duration: number | null;                 // 毫秒
  ttft: number | null;                     // Time to First Token，毫秒
  thread_id: string | null;
  visibility_mode: "default" | "hidden";
  llm_span_count: number;
  has_tool_spans: boolean;
  providers: string[];
  experiment: ExperimentItemReference | null;
  source: "sdk" | "experiment" | "playground" | "optimization" | null;
}

interface ErrorInfo {
  exception_type: string;
  message: string;
  traceback: string;
}

interface FeedbackScore {
  name: string;
  category_name: string | null;
  value: number;
  reason: string | null;
  source: "ui" | "sdk" | "online_scoring";
  created_at: string;
  last_updated_at: string;
  created_by: string;
  last_updated_by: string;
  value_by_author: Record<string, ValueEntry> | null;
}

interface ValueEntry {
  value: number;
  reason: string | null;
  category_name: string | null;
  source: string;
  last_updated_at: string;
  span_type: string | null;
  span_id: string | null;
}

interface Comment {
  id: string;
  text: string;
  created_at: string;
  last_updated_at: string;
  created_by: string;
  last_updated_by: string;
}

interface ExperimentItemReference {
  id: string;
  name: string;
  dataset_id: string;
  dataset_item_id: string;
}
```

### 三、过滤器格式（`filters` 参数）

所有列表接口的 `filters` 参数都是 URL 编码的 JSON 数组：

```typescript
interface Filter {
  field: string;       // 字段名
  type: string;        // 字段类型
  operator: string;    // 运算符
  value: string;       // 值
  key?: string;        // DICTIONARY/FEEDBACK_SCORES 类型的子键
}
```

**示例（你给的 URL 解码后）：**

```json
[
  {"field": "thread_id", "type": "string", "operator": "=", "value": "agent:main:main"},
  {"field": "visibility_mode", "type": "string", "operator": "=", "value": "default"}
]
```

**Trace 可过滤字段：**

| field     | type | 说明         |
| ----------- | ------ | -------------- |
| `id`          | `string`     | Trace ID     |
| `name`          | `string`     | 名称         |
| `start_time` / `end_time` / `created_at` / `last_updated_at` | `date_time`     | 时间         |
| `input` / `output`       | `string`     | 输入输出文本 |
| `metadata`          | `dictionary`     | 需要 key     |
| `total_estimated_cost`          | `number`     | 费用         |
| `duration` / `ttft`       | `number`     | 耗时         |
| `tags`          | `list`     | 标签         |
| `usage.completion_tokens` / `usage.prompt_tokens` / `usage.total_tokens`    | `number`     | Token        |
| `feedback_scores` / `span_feedback_scores`       | `feedback_scores_number`     | 需要 key     |
| `thread_id`          | `string`     | 线程 ID      |
| `error_type`          | `string`     | 错误类型     |
| `visibility_mode`          | `string`     | 可见性       |
| `experiment_id`          | `string`     | 实验 ID      |
| `source`          | `string`     | 来源         |

**运算符：**  `=`, `!=`, `>`, `>=`, `<`, `<=`, `contains`, `not_contains`, `starts_with`, `ends_with`, `is_empty`, `is_not_empty`

### 四、页面 → 接口优先级矩阵

帮你规划开发顺序：

| 优先级 | 页面            | 必需接口数 | 核心接口                   |
| -------- | ----------------- | ------------ | ---------------------------- |
| **P0**       | 项目列表        | 4          | `GET /projects/`, `GET /projects/stats`, `POST /projects/`, `DELETE /projects/{id}`                     |
| **P0**       | Trace 列表      | 4          | `GET /traces/`, `GET /traces/stats`, `GET /traces/feedback-scores/names`, `GET /projects/{id}`                     |
| **P1**       | Thread 列表     | 3          | `GET /traces/threads`, `GET /traces/threads/stats`, `GET /traces/threads/feedback-scores/names`                       |
| **P1**       | Span 列表       | 3          | `GET /spans/`, `GET /spans/stats`, `GET /spans/feedback-scores/names`                       |
| **P1**       | Trace 详情面板  | 3          | `GET /traces/{id}`, `GET /spans/?trace_id=X`, `GET /feedback-definitions/`                       |
| **P2**       | Thread 详情面板 | 2          | `POST /traces/threads/retrieve`, `GET /traces/?filters=[thread_id=X]`                         |
| **P2**       | 评分/评论/标签  | 12         | 各种 PUT/POST/PATCH 写接口 |
| **P3**       | 批量操作        | 6          | batch delete/update 接口   |

这就是 Projects 页面涉及的**全部 35 个接口**和完整数据结构。你可以按优先级逐步实现页面功能！
